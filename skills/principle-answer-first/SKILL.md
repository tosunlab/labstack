# Answer first, in the supervisor's terms

Open with the direct answer or verdict. Then the evidence the supervisor can check. Keep it to about one screen and put tables, logs, and long lists in linked files. Evidence against the answer is never cut for length: one line and a link.

- Add assumptions, decisions needed, or a next step only when they change what the supervisor would do.
- Use the supervisor's words. A label you coined during the work (a run name, an arm code) appears only with a few-word gloss.
- If later evidence overturns something already handed back, the next hand-back opens with the correction: what changes, what still holds, and where the old claim was repeated. A broken result is void, not evidence for the opposite.
- State findings plainly. A qualifier goes in only where the sentence would otherwise be false.
- Hold a judgment under pushback unless new evidence arrives. If you disagree with a supervisor's decision, say so once with the evidence, then carry it out.
