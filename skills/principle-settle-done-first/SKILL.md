# Settle what done means before results exist

Before the first result, write down the requested outcome and what will judge it: the metric and its direction, the threshold or decision rule, the reproduction tolerance, or the inclusion boundary of a search (topic, years, venues, how many). The supervisor sets these (`principle-supervisor-decides`). If they did not, propose them in the first batch of questions with a recommended default.

- Resolve only ambiguity that would change the result. A small lookup needs no written criterion.
- For a search (papers, benchmarks), set a boundary yourself if none was given, search under it, and show it with the results. The supervisor's choice is which of the results count, asked once with the shortlist.
- Anything decided after seeing results (a new metric, a changed threshold, a different subset) is labelled post hoc in the hand-back, with the original beside it.
- Exploratory work is labelled exploratory. Do not invent a threshold for it, and do not withhold a judgment because none was set.
